Ajuda - Busca de Artigos no Crossref

Esta ferramenta consulta a base de dados do Crossref e exibe informações de artigos científicos: título, autores, revista, ISSN, volume, páginas, DOI, abstract e referência no modelo APA.

1. Como usar

  1. No campo de texto, digite o valor correspondente à opção escolhida (por exemplo, um DOI, um título, um nome de autor).
  2. No seletor Opção, escolha o tipo de busca desejado.
  3. Defina a ordenação (campo e direção).
  4. Escolha a quantidade de registros a exibir.
  5. Clique em Buscar ou pressione Enter.

Os resultados aparecem abaixo do formulário. Durante a consulta é exibida a mensagem "Aguarde carregando os registros...".

2. Opções de busca

DOI do artigo

Busca exata pelo DOI (Digital Object Identifier). É a forma mais precisa e retorna apenas o artigo correspondente.

Exemplo: 10.1590/S0102-311X2020000100001

Prefixo DOI

Retorna todos os artigos que compartilham o mesmo prefixo de DOI (normalmente associado a um publisher ou instituição).

Exemplo: 10.1590

Título

Busca por palavras no título do artigo. A ferramenta aplica um filtro adicional: todas as palavras digitadas devem estar presentes no título para que o registro seja exibido. Isso elimina resultados genéricos retornados pela API.

Exemplo: saúde mental pandemia

Atenção: palavras com menos de 3 letras são ignoradas pelo filtro (artigos, preposições e conjunções como "de", "da", "os", "um").

Autor(es)

Busca por nome de autor. A ferramenta valida se ao menos um dos autores do artigo contém todas as palavras informadas no nome (sobrenome e/ou nome).

Exemplo: Silva João ou Silva

ISSN

Busca exata pelo ISSN da revista (International Standard Serial Number). Retorna artigos publicados naquele periódico.

Exemplo: 0102-311X

Afiliação Institucional

Busca por instituição declarada pelos autores. A ferramenta valida se ao menos uma afiliação contém todas as palavras informadas.

Exemplo: Universidade de São Paulo

Nome do Publisher

Busca pelo nome da editora responsável pela publicação. A ferramenta valida se todas as palavras estão presentes no nome do publisher.

Exemplo: Elsevier

3. Ordenação dos resultados

É possível escolher o critério de ordenação:

  • Relevância - mais relevantes primeiro (recomendado para buscas textuais).
  • Última atualização - registros atualizados mais recentemente.
  • Data de depósito - data em que o registro foi incluído no Crossref.
  • Data de publicação - data de publicação do artigo.
  • Data de emissão - data de emissão do DOI.
  • Publicado (impresso) - data da versão impressa.
  • Publicado (online) - data da versão online.

Também é possível escolher a direção: crescente ou decrescente.

Dica: para buscas por título, autor, afiliação ou publisher, prefira a ordenação por Relevância, pois ela usa a pontuação calculada pela própria API.

4. Quantidade de resultados

O seletor de linhas define quantos registros a ferramenta exibirá. Para buscas textuais (título, autor, afiliação, publisher), a ferramenta consulta um número maior na API e depois filtra, garantindo que você receba resultados realmente relevantes.

5. Referência APA

Marque a caixa Gerar referência APA para que cada resultado inclua uma referência formatada no modelo APA, com autores, ano, título, revista, volume, número, páginas e DOI.

O botão Copiar Referência ao lado permite copiar o texto para a área de transferência.

6. Copiar DOI e Referência

  • Copiar DOI - copia o DOI do artigo.
  • Copiar Referência - copia o texto da referência APA (disponível apenas se a opção estiver marcada).

Ao copiar com sucesso, é exibida a mensagem "Copiado para a área de transferência!".

Observação: o nave中间dor precisa permitir o acesso à área de transferência. Em conexões não seguras (HTTP), a cópia pode falhar. Use HTTPS ou localhost.

7. Visualizar o abstract

Cada resultado possui um botão Abstract. Ao clicar, o resumo do artigo é expandido. Clique novamente para recolher. Se o artigo não tiver abstract cadastrado no Crossref, é exibida a mensagem "Sem abstract.".

8. Por que alguns resultados são descartados

A API do Crossref realiza buscas textuais amplas e pode retornar registros que contenham apenas parte dos termos digitados, além de registros de tipos que não são artigos de revista. Para garantir qualidade, a ferramenta aplica filtros adicionais no navegador:

  • Filtro por tipo - apenas artigos de revista (journal-article) e revistas (journal) são exibidos.
  • Filtro por campo - o termo digitado é validado no campo correspondente (título, autor, afiliação ou publisher).
  • Filtro por pontuação - registros com pontuação de relevância muito baixa são descartados.

O contador no topo dos resultados mostra quantos registros foram exibidos, quantos a API retornou e quantos foram descartados.

Se o filtro rigoroso não retornar nenhum resultado, a ferramenta relaxa o filtro automaticamente e exibe os melhores resultados por relevância, com o aviso "filtro relaxado".

9. Dicas por tipo de busca

Título

  • Use 2 a 5 palavras significativas do título.
  • Evite palavras muito comuns (artigos, preposições).
  • Se não encontrar nada, reduza o número de palavras.

Autor

  • Informe o sobrenome primeiro: Silva João.
  • Se houver muitas variantes do nome, busque apenas pelo sobrenome.
  • Nomes com acento são normalizados automaticamente.

Afiliação

  • Use o nome oficial da instituição.
  • Evite siglas isoladas; prefira o nome completo.

Publisher

  • Use o nome exato ou parte dele.
  • Para editoras com nomes compostos, informe as palavras principais.

DOI e Prefixo

  • Cole o DOI completo, sem a URL (https://doi.org/).
  • Para prefixo, informe apenas a parte numérica inicial.

10. Solução de problemas

"Um valor DEVE ser informado!"

O campo de busca está vazio. Digite um valor antes de buscar.

"Uma opção deve ser selecionada!"

Nenhuma opção de busca foi escolhida no seletor.

"Uma opção de ordenamento deve ser selecionada!"

Nenhuma direção de ordenação (crescente ou decrescente) foi marcada.

"Erro ao carregar os DOIs!"

A consulta à API falhou. Verifique:

  • Sua conexão com a internet.
  • Se o valor informado é compatível com a opção escolhida.
  • Se a API do Crossref está disponível (tente novamente em alguns instantes).

"Nenhum resultado relevante encontrado"

A API retornou registros, mas nenhum passou pelo filtro de campo. Tente:

  • Reduzir o número de palavras.
  • Usar termos mais gerais.
  • Trocar a opção de busca (por exemplo, de Título para Autor).

"Erro ao copiar texto"

O navegador bloqueou o acesso à área de transferência. Verifique se a página está em HTTPS ou em localhost. Em alguns navegadores, é necessário conceder permissão manualmente.

Resultados demoram a aparecer

Buscas textuais amplas podem demorar mais. Reduza a quantidade de linhas ou use termos mais específicos.

Informações técnicas

  • Fonte dos dados: API pública do Crossref (https://api.crossref.org/works).
  • Normalização: acentos, pontuação e caixa são ignorados nos filtros.
  • Privacidade: nenhum dado é armazenado; as consultas são feitas diretamente do navegador à API do Crossref.
